# LLM Forecast Text

**What it is.** Short pieces of forecast text written by a language model (an "LLM") from
weather model and observation data, shown on the site with a clear label that no human wrote
them. Each piece comes in three versions for three kinds of reader.

**Where it stands (20 Nov 2026):** the rules, the upload check and, since 1.7.7, the part of
the site that draws the text are all on `.dev`. The text itself does not exist yet: the
producers have still to build the runs that write it. Until a real file arrives the two blocks
that are wired in (the homepage summary and the weather page discussion) stay hidden and
empty, with no placeholder. **No LLM text is on the site today.** Nothing goes to the public
site until real text is flowing; that release is version 1.8.0.

## The three tiers

Every block of text has three tabs and always opens on the first:

| Tab | Written for | Sounds like |
|---|---|---|
| **Public** | Anyone | Plain words, °F and mph, what it means for your day |
| **Industry** | People planning work around the weather | Timing, ranges, how sure, what to plan for |
| **Expert** | Forecasters and researchers | The reasoning: model runs, ensemble spread, SI units |

## Who writes it

Two "personas" (two prompts with different jobs) run on the university computer, not on the
website. Readers never see their names: the site says "LLM forecast".

- **Ffion**, the communicator, four times a day. She writes every Public and Industry tab.
- **Rhiannon**, the nowcaster, eight times a day. She writes for forecasters only: Expert tabs
  about what the instruments and aircraft are showing now. She never writes a Public tab, and
  the server refuses a file in which she does.

## The promises the site keeps

- **The site only shows text; it never writes or edits any.** There is no LLM on the website
  and no LLM bill for it. It does not shorten text either, so each piece is written to a word
  budget and refused if it runs more than half as long again.
- **Old text disappears.** A block is hidden, with no placeholder, when its text is more than
  two runs old (12 hours for Ffion, 6 for Rhiannon), past its own "valid until" time, or about
  an older model run than the chart beside it.
- **It is always labelled.** Every tab says the text was generated by an LLM and to check
  official forecasts. It is styled apart from the forecasters' own outlooks.
- **A colour is never decided by generated text.** The homepage lights use fixed rules, and
  the ozone light reads the human outlook only.
- **Text goes on the page as plain text.** No formatting codes from the file are run.

**See a refusal** (nothing is stored):

```bash
echo '{}' > /tmp/llm_forecast_ffion_20261203_1210Z.json
curl -s -X POST https://www.basinwx.dev/api/upload/llm_forecasts \
  -H "x-api-key: $BASINWX_API_KEY" -H "x-client-hostname: $(hostname -f)" \
  -F "file=@/tmp/llm_forecast_ffion_20261203_1210Z.json" | python3 -m json.tool
```

**Tests:** `public/js/__tests__/llmForecast.test.js` (each test is also a rule a producer must
meet; one fails if the manifest and the code disagree), the `llm_forecasts uploads` block in
`server/__tests__/uploadPolicy.test.js`, and `public/js/__tests__/llmText.test.js` (when a
block is drawn, when it is not, what it says).

**To see it before real text exists,** run a branch preview and fill its own `llm_forecasts`
folder with `node scripts/preview-llm-samples.mjs <that folder>` (README "Branch previews").
Every sample begins "SAMPLE TEXT, NOT A FORECAST." and goes stale after 6 to 12 hours.
